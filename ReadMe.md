# ML-DL-Projects-From-Scratch-and-With-Libraries

This repository serves as a collection of **Machine Learning (ML)** and **Deep Learning (DL)** projects implemented using both **established ML/DL libraries** and **pure NumPy-based from-scratch approaches**.

The primary objective of this repository is to provide a clear comparison between:
- **Library-based implementations**, commonly used in real-world and industry applications
- **From-scratch implementations**, designed to build strong foundational and mathematical understanding

---

## 📌 Scope of the Repository

- Implementation of core ML and DL algorithms
- Supervised learning models for classification and regression
- End-to-end model training workflows
- Model evaluation and performance analysis
- Conceptual and mathematical insights behind algorithms

---

## 🧠 Implementation Strategies

### 🔹 Framework-Based Implementations
Projects in this category utilize:
- **scikit-learn**
- **TensorFlow / Keras**
- **PyTorch**

These implementations emphasize:
- Readable and modular code structure
- Reproducibility and scalability
- Industry-standard training practices

---

### 🔹 From-Scratch Implementations (NumPy)
Projects in this category are implemented without ML/DL frameworks, relying solely on:
- **NumPy**
- **Core Python constructs**

These implementations emphasize:
- Manual derivation of gradients
- Explicit forward and backward propagation
- Custom optimization techniques
- Deep understanding of model internals
